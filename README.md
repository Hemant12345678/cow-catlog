# 🐄 Cow Catalog - Angular 18 Standalone
A simple Angular 18 application to manage a Cow Catalog — list, filter, search, view, and add cows — built using standalone components (no modules or routing).
---
## 🚀 Features Implemented
  Cow List – Shows cows with ear tag, sex, pen, status, and last event date  
 Search & Filter – Filter cows by tag, pen, or status  
 Cow Detail – View full details of a selected cow  
---
## ⚙️ Tech Stack
- Angular 18 (standalone)
- RxJS (BehaviorSubject for reactive data)
- HTML, CSS, TypeScript (no external libraries)
